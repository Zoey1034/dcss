# Tabbar Icons

Please add the following icon files to this directory:

- `home.png` / `home-active.png` - 首页图标
- `file.png` / `file-active.png` - 文件图标
- `review.png` / `review-active.png` - 审核图标
- `profile.png` / `profile-active.png` - 个人中心图标

Recommended size: 81x81 pixels for best display quality.

You can use icon libraries like:
- https://www.iconfont.cn/
- https://www.iconfinder.com/
- https://icons8.com/

Or create simple icons using design tools.
